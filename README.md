# Sakshi Rodge — Animated Data Analyst Portfolio

### Added
- Animated typing headline
- Animated analytics dashboard and graph bars
- Floating KPI cards
- Floating Python / SQL / Power BI badges
- Glow and grid background
- Scroll reveal animations
- Active navbar underline that changes while scrolling
- Responsive mobile navigation

### Run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install **Live Server** by Ritwick Dey.
4. Open `index.html`.
5. Right-click → **Open with Live Server**.
6. Chrome responsive mode: `Ctrl + Shift + I`, then `Ctrl + Shift + M`.

Replace the email and GitHub placeholder links before publishing.
